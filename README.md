# deanfeed

[deanfeed](https://deanfeed.me) 홈페이지. Obsidian 플러그인 deanfeed 의 "홈페이지에 발행" 명령이 내용을 채우고, GitHub Actions 가 [Quartz](https://quartz.jzhao.xyz) 로 빌드해 GitHub Pages 에 올립니다.

- `content/` — 발행된 내용 (플러그인이 덮어씀): 홈 앱 데이터, 아티클·영구메모·메모 페이지, 첨부
- `custom/DfNav.tsx`, `quartz/styles/custom.scss` — deanfeed 내비와 스타일
- `quartz/static/deanfeed-web.*` — 홈 화면(읽기 전용 deanfeed 앱)
